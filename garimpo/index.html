01

deepseek-harness

deepseek-ai/deepseek-harness
  • ★ 238 mil
  • Licença MIT
  • Versão de testes
O que é

Um agente de IA open source feito pela DeepSeek AI, com arquitetura em que tudo é plugin. O comando é dsh e ele abre uma interface web local. Como cada parte é um plugin, você troca o que não gostou sem trocar o sistema inteiro.

Antes de começar
  • Node.js instalado
  • De preferência, um computador ou máquina virtual de testes (veja o cuidado abaixo)
Instalar e abrir

Um comando só. Ele sobe a interface em http://127.0.0.1:3080 e abre no navegador.

npx @deepseek-ai/dsh web

Para rodar sem abrir o navegador:

npx @deepseek-ai/dsh web --no-open
Rodar a partir do código-fonte
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
Onde aprender mais

Documentação: deepseek-harness.github.io/deepseek-harness. Plugins da comunidade ganham o tópico dsh-plugin no GitHub.

Casos de uso
  • Testar como um agente modular se comporta, trocando plugins sem reinstalar tudo.
  • Experimentar plugins da comunidade e criar o seu próprio.
  • Montar um laboratório de agentes num ambiente isolado antes de levar algo para o trabalho.
Sobre estes casos de uso

O README do projeto ainda é enxuto e não traz exemplos prontos. Os casos acima são o uso natural de um agente modular, não receitas da documentação.

Cuidado
  • É uma versão de desenvolvedor (developer preview). O próprio projeto avisa que haverá mudanças que quebram compatibilidade.
  • Não passou por auditoria de segurança e não deve ser tratado como pronto para produção.
  • Ele pode executar código e comandos gerados por modelo, carregar plugins de terceiros e acessar rede, arquivos e credenciais que você liberar.
  • A recomendação do projeto: usar uma máquina virtual ou contêiner descartável, o mínimo de acesso, manter backup e revisar plugins e comandos antes de deixar rodar.
02

firecrawl

firecrawl/firecrawl
  • ★ 186 mil
  • AGPL-3.0 (SDKs em MIT)
  • Hospedado ou self-host
O que é

Uma API para buscar, raspar e interagir com a web em escala. Ela entrega o conteúdo em Markdown limpo ou dados estruturados, prontos para o seu agente usar. Pega páginas cheias de JavaScript e também PDFs e DOCX publicados na web. É open source e também existe como serviço hospedado.

O que ela faz
  • Search: pesquisa na web e já traz o conteúdo completo dos resultados.
  • Scrape: transforma qualquer URL em Markdown, HTML, captura de tela ou JSON.
  • Crawl: lê todas as páginas de um site com um único pedido.
  • Map: lista todas as URLs de um site.
  • Batch Scrape: raspa milhares de URLs de forma assíncrona.
  • Interact e Agent: clica e navega em páginas, ou você descreve o que quer e ele busca.
Antes de começar
  • Uma chave de API: cadastre-se em firecrawl.dev (o serviço hospedado), ou hospede você mesmo seguindo o guia de self-hosting em docs.firecrawl.dev/contributing/self-host
Instalar o SDK

Python:

pip install firecrawl-py

Node.js:

npm install firecrawl
Primeiro uso (Python)
from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-SUA_CHAVE")
resultado = app.scrape('firecrawl.dev')
print(resultado)
Ligar ao seu agente de IA

Com uma linha, você instala o skill do Firecrawl no seu agente (Claude Code e outros). Reinicie o agente depois. Se preferir MCP, use a configuração abaixo.

npx -y firecrawl-cli@latest init --all --browser

Configuração de MCP:

{
  "mcpServers": {
    "firecrawl-mcp": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "fc-SUA_CHAVE" }
    }
  }
}
Casos de uso
  • Transformar um site de documentação inteiro em Markdown para a sua IA ler e responder com base nele (Crawl).
  • Pesquisar um assunto e receber o texto completo das melhores páginas, sem abrir uma por uma (Search).
  • Acompanhar página de preços ou de produtos de concorrentes e trazer os dados organizados (Scrape).
  • Pedir em linguagem natural algo como "ache os planos de preço do Notion" e deixar o agente navegar (Agent).
Cuidado
  • Uso em escala consome créditos. No exemplo do README, um crawl de 50 páginas gastou 50 créditos. Confira o plano atual no site antes de rodar coisas grandes.
  • O que você raspa é responsabilidade sua: respeite os termos de uso do site e as leis de dados pessoais (como a LGPD).
  • A licença AGPL-3.0 tem obrigações se você modificar o código e oferecê-lo como serviço. Se for comercializar, consulte um advogado.
03

Graphify

Graphify-Labs/graphify
  • ★ 122 mil
  • Licença Apache-2.0
  • Grátis
O que é

Você digita /graphify no seu assistente de IA de código e ele mapeia o projeto inteiro (código, documentos, PDFs, imagens, vídeo) num grafo de conhecimento que você consulta em vez de vasculhar arquivo por arquivo. Cada conexão vem marcada como EXTRACTED (estava escrita na fonte) ou INFERRED (deduzida), então dá para saber o que foi lido e o que foi inferido. Não é um índice de vetores: é um grafo de verdade.

Antes de começar
  • Python 3.10 ou mais novo
  • uv (recomendado) ou pipx
  • Um assistente de IA compatível: Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot e mais de 15 outros
Instalar

Atenção: o nome do pacote tem dois y (graphifyy). O comando continua sendo graphify.

uv tool install graphifyy

Registrar o skill no seu assistente de IA:

graphify install
Usar

Abra o assistente na pasta do projeto e digite:

/graphify .

No PowerShell, sem a barra:

graphify .
O que você recebe
  • graph.html: abre no navegador, dá para clicar nos nós, filtrar e buscar.
  • GRAPH_REPORT.md: os conceitos principais, as ligações surpreendentes e perguntas sugeridas.
  • graph.json: o grafo completo, para consultar quando quiser sem reler os arquivos.
Consultar o grafo
graphify query "como funciona o login?"
graphify path "NomeA" "NomeB"
graphify explain "NomeDoConceito"
Extras (instale só o que precisar)

PDFs, Word/Excel e vídeo/áudio:

uv tool install "graphifyy[pdf]"
uv tool install "graphifyy[office]"
uv tool install "graphifyy[video]"
Casos de uso
  • Entender um projeto herdado: ver os conceitos mais conectados e as partes do sistema.
  • Descobrir como duas coisas se ligam (graphify path) sem abrir dezenas de arquivos.
  • Juntar código, documentação e PDFs de um projeto no mesmo mapa e perguntar sobre tudo de uma vez.
  • Fazer o assistente consultar o grafo antes de ler arquivos, gastando menos contexto.
Cuidado
  • O pacote oficial se chama graphifyy, com dois y. Outros pacotes graphify* no PyPI não são afiliados ao projeto: instalar o errado é risco de pacote falso.
  • O código é analisado localmente e não sai da sua máquina. Já documentos, PDFs, imagens e vídeo passam por um modelo de IA (o do seu assistente ou uma chave de API que você configurar), então o conteúdo sai do computador e consome uso.

gemini-cli

google-gemini/gemini-cli
  • ★ 107 mil
  • Licença Apache-2.0
  • Plano grátis com limite
O que é

O agente de IA open source do Google que roda no seu terminal. Dá acesso direto ao Gemini, com janela de contexto de 1 milhão de tokens, e traz ferramentas prontas: busca no Google, leitura e edição de arquivos, comandos de shell e leitura de páginas da web. Também aceita MCP para ligar outras ferramentas.

Antes de começar
  • Node.js (para npx ou npm) ou Homebrew (macOS e Linux)
  • Uma conta Google pessoal
Instalar (escolha um)

Rodar sem instalar:

npx @google/gemini-cli

Instalar com npm:

npm install -g @google/gemini-cli

Instalar com Homebrew:

brew install gemini-cli
Primeiro uso

Na pasta do seu projeto, rode o comando abaixo, escolha Sign in with Google e siga o login no navegador.

gemini
Plano grátis

Entrando com uma conta Google pessoal, o README informa 60 pedidos por minuto e 1.000 por dia, sem precisar de chave de API. Se precisar de mais, dá para usar uma chave da API do Gemini ou o Vertex AI.

Comandos úteis

Pergunta direta, sem abrir a conversa (bom para scripts):

gemini -p "Explique a arquitetura deste código"

Resposta em JSON:

gemini -p "Explique a arquitetura deste código" --output-format json

Incluir outras pastas no contexto:

gemini --include-directories ../lib,../docs
Casos de uso
  • Entender um código que você acabou de receber: pedir um resumo das mudanças de ontem ou da arquitetura.
  • Gerar um app novo a partir de um PDF, uma imagem ou um esboço, usando a leitura multimodal.
  • Automatizar tarefas de repositório, como consultar pull requests ou resolver rebases complexos.
  • Revisar pull requests e organizar issues sozinho, usando a GitHub Action do projeto.
  • Guardar as regras do seu projeto num arquivo GEMINI.md para ele sempre agir do seu jeito.
Cuidado
  • O que é grátis é o uso, com teto: 1.000 pedidos por dia na conta pessoal. A conta, as credenciais e o limite continuam sendo seus.
  • Nunca coloque sua chave de API dentro de um repositório.
  • Os canais preview e nightly podem ter falhas (o README avisa). Para o dia a dia, use a versão estável (latest).
As estrelas (★) são as do GitHub em 27/09/2026. Antes de instalar qualquer coisa, abra o link oficial do repositório e confirme que é ele mesmo.
