#NEEDLE

Needle: IA de 14 MB que roda sem internet (e devolve JSON)

O Needle é um modelo de IA inteiro dentro de um binário de 8 a 29 MB: sem nuvem, sem API, sem internet. Ele não conversa — ele decide e extrai: você declara as funções que o seu aparelho tem, o usuário pede em linguagem natural e o modelo devolve a chamada pronta em JSON, com a confiança de cada resposta. Este kit tem o comando de instalação que funciona hoje, o exemplo de texto para JSON, a chamada de função na prática e o caminho para rodar no aparelho. 02

Instalar e rodar em 3 minutos

cactus-compute/needle
  • Python
  • Grátis
  • Apache-2.0
Como instalar e usar3 etapas com comandos prontos para copiar

Instalar

O pacote oficial no PyPI (versão 3.0.6 em 30/09/2026):

pip install cactus-needle

Se você for fazer ajuste fino (fine-tuning):

pip install "cactus-needle[train]"

O primeiro exemplo (o do próprio README oficial)

A função que você decora é a ferramenta: a assinatura define os tipos dos argumentos, e o texto de dentro das aspas é a descrição que o modelo lê para escolher.

salve como teste.py e rode:

import needle

@needle.tool
def get_weather(city: str):
    "Get the current weather for a city."
    return {"city": city, "temp_c": 27, "sky": "clear"}

agent = needle.Needle(tools=[get_weather])
print(agent.run("what's it like in Lagos right now?")["results"])
# [{'city': 'Lagos', 'temp_c': 27, 'sky': 'clear'}]

Já usava o Needle 2?

O mesmo pacote continua rodando a geração anterior: é só passar `generation=2` na criação do objeto.

agent = needle.Needle(tools=[get_weather], generation=2)
03

Texto → JSON: o que interessa para quem automatiza

cactuscompute.com
  • Sem API
  • Roda offline
Como funciona

Você declara o formato da saída (o registro), entrega o texto bagunçado e recebe os campos tipados de volta: uma nota fiscal, um agendamento, um aviso, um formulário. A gramática de saída garante que o resultado sempre possa ser lido por um programa — e o mesmo mecanismo serve para classificar.

Onde isso resolve no dia a dia
  • Nota ou cupom que chega por mensagem → campos separados sem ninguém digitar
  • Mensagem de cliente → urgente / não urgente, com a confiança da decisão
  • Texto solto → linha de planilha, pronta para o sistema
  • Busca local: o mesmo modelo devolve vetor (embedding) para achar e rotear sem internet
Passo a passo do guia oficial

O guia mostra o registro como a **única** ferramenta do agente, os resultados tipados e a classificação com lista fechada de opções. Vale ler antes de desenhar o seu primeiro caso.

04

As duas pegadinhas (leia antes de confiar)

  • Importante
  • Vem da fonte oficial

1 · Ele devolve lista vazia, não um chute

Se o usuário pedir algo que nenhuma ferramenta declarada cobre, a resposta é uma lista vazia. Isso é decisão de projeto, não bug: ele prefere não responder a inventar. O efeito colateral é que a qualidade do resultado depende da **sua lista de ferramentas** — se ela estiver mal desenhada, ele simplesmente não faz.

2 · A confiança é calibrada, mas não é garantia

Toda resposta vem com um número de confiança (por exemplo, 0,94) calculado pelo próprio modelo. Ele pode escolher a ferramenta errada com confiança alta. Por isso o guia oficial ensina a rotear em três caminhos — agir, confirmar ou recusar — em vez de obedecer sempre.

3 · Ele não é um chatbot

O próprio projeto diz: trocaram capacidade de conversa geral por ganhar de modelos 10 vezes maiores em chamada de ferramenta no aparelho. Para texto longo e criativo, continue na nuvem.

05

Levar para o aparelho (celular, relógio, robô)

cactuscompute.com
  • 8–29 MB
  • Roda no próprio hardware
O caminho
  • O modelo é um arquivo único (formato .cact) que o motor lê no lugar — sem carregar tudo na memória
  • Pesos e motores por plataforma ficam no Hugging Face (Android, iOS, relógios, Linux, navegador)
  • Existe CLI para rodar e testar, API em C para embutir, além de navegador e WASI
  • Funciona em rede isolada (air-gapped): nenhum dado sai do aparelho
Como instalar e usar1 etapa com comandos prontos para copiar

Comando de exemplo (do site oficial)

rodar como serviço local, escutando pedidos:

./needle --model needle3.cact --tools tools.json --serve

ou um pedido só, na linha de comando:

./needle --model needle3.cact --tools tools.json --prompt "dim the living room to 30"
06

O que muda no Needle 3

cactuscompute.com
  • 8 a 29 MB
  • 121 M de parâmetros
  • 2 a 20 camadas
O mesmo modelo, em fatias

O Needle 3 foi treinado para que **toda a profundidade, de 2 a 20 camadas, seja um modelo que dá para usar**. Você corta camadas até caber no aparelho que tem — o mesmo modelo, menor, e não um modelo aleatório reduzido.

Por que 121 milhões de parâmetros cabem em 14 MB

A maior parte dos parâmetros está na memória de n-gramas (engram), então o modelo de 121 milhões faz a conta de um de 50 milhões. É compressão de 2 bits e pesos embutidos no binário.

Números oficiais (30/09/2026)
  • Binário único de 8 a 29 MB
  • 121 M de parâmetros na versão cheia (a maior parte no engram)
  • Cerca de 28 MB de RAM numa sessão inteira
  • Licença Apache-2.0 — uso comercial liberado
  • 12.913 estrelas no GitHub em 30/09/2026
Comece pelo exemplo de 3 minutos: instale, rode o teste do tempo com uma função sua e veja o JSON voltar. Se funcionar, o próximo passo é o guia de extração estruturada — é ali que ele substitui digitação. E antes de ligar em algo que decide de verdade, leia o guia de confiança: agir, confirmar ou recusar é uma escolha sua, não do modelo.
