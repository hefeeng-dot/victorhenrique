Agency Agents

msitarzewski/agency-agents
  • ★ 155 mil
  • Fácil: tem app

Uma coleção de agentes especialistas prontos (marketing, revisão, produto, desenvolvimento e muitos outros), cada um com personalidade, processo e entregas definidas. O app instala os agentes no Claude Code, Cursor, Codex, Gemini CLI e outros com um clique e mantém tudo atualizado.

Como começar (sem terminal)
  • Baixe o app em agencyagents.app (Mac, Windows e Linux).
  • Escolha os agentes que fazem sentido para você e clique para instalar na ferramenta que você usa.
  • Abra uma conversa nova e peça para ativar o agente pelo nome.

Casos de uso

  • Ter um revisor de textos ou de posts com um jeito de trabalhar definido.
  • Montar um "time" de especialistas para um projeto pessoal.
  • Usar os arquivos como modelo para escrever os seus próprios agentes.

Cuidado

São prompts bem feitos, não mágica. Escolha dois ou três que resolvem algo seu, em vez de instalar todos.

Prompt
Ative o agente [nome do agente] e revise o texto abaixo como esse especialista faria. Me devolva: 1) os 3 maiores problemas, 2) a versão corrigida, 3) uma nota de 0 a 10 e o que falta para subir 2 pontos.

Texto:
[cole aqui]
Como instalar e usar1 etapa com comandos prontos para copiar

Com terminal (Claude Code)

Dentro da pasta do projeto clonado:

./scripts/install.sh --tool claude-code

AdGuard Home

AdguardTeam/AdGuardHome
  • ★ 37,1 mil
  • Médio: painel no navegador

Um servidor de DNS que você mesmo hospeda e que bloqueia anúncios e rastreadores para todos os aparelhos da rede da casa, sem instalar nada em cada um.

Casos de uso

  • Menos anúncio em TV, celular e computador de toda a família.
  • Ver quais aparelhos acessam o quê e bloquear sites específicos.

Cuidado

Se esse aparelho desligar, a internet da casa pode parar até você voltar o DNS do roteador para o padrão. Anote o DNS original antes de trocar.

Como instalar e usar1 etapa com comandos prontos para copiar

Antes de começar

  • Um aparelho que fique ligado o tempo todo: um Raspberry Pi, um PC antigo ou um servidor em casa.
  • Acesso ao painel do seu roteador, para trocar o DNS.

Instalar (Linux ou Mac)

curl -s -S -L https://raw.githubusercontent.com/AdguardTeam/AdGuardHome/master/scripts/install.sh | sh -s -- -v
Depois de instalar
  • Abra no navegador o endereço que o instalador mostra no final e siga o assistente (crie usuário e senha).
  • No roteador, troque o DNS para o endereço IP do aparelho onde o AdGuard Home está rodando.
  • Guia oficial com prints, inclusive para outros sistemas: adguard-dns.io

hyperresearch

jordan-gibbs/hyperresearch
  • ★ 3,7 mil
  • Licença MIT
  • Médio: precisa de Claude Code ou Codex

Transforma o Claude Code ou o Codex num agente de pesquisa: busca na web, lê, sintetiza e guarda tudo numa wiki local pesquisável, que cresce a cada pesquisa.

Casos de uso

  • Comparar produtos, ferramentas ou fornecedores com as fontes guardadas.
  • Montar uma base de conhecimento sobre um tema e consultar depois.

Cuidado

É o menor e mais novo da lista. Pesquisa longa consome bastante do seu plano ou dos seus créditos.

Prompt
/hyperresearch Quais são as melhores opções de [ferramenta/produto] para [seu caso] em 2026? Compare preço, prós, contras e para quem cada uma serve. Termine com uma recomendação e liste as fontes.
Como instalar e usar1 etapa com comandos prontos para copiar

Antes de começar

  • Python 3.11 a 3.14.
  • Claude Code ou OpenAI Codex instalado.

Instalar no Claude Code

Dentro da pasta do seu projeto:

(não alterar o bloco de código) se quiser citar a fonte do pacote na seção, use https://pypi.org/project/hyperresearch/
hyperresearch install

Depois, no Claude Code:

/hyperresearch <sua pergunta>

OpenMontage

calesthio/OpenMontage
  • ★ 61,7 mil
  • AGPL-3.0
  • Avançado

Um sistema de produção de vídeo comandado pelo seu agente de código: pesquisa, roteiro, narração, imagens, música, legendas e render, tudo por conversa. Tem caminho gratuito com imagens e vídeos de bancos livres e narração offline.

Casos de uso

  • Vídeos explicativos para redes sociais sem abrir editor.
  • Montagens com imagens reais de bancos gratuitos, com música e legenda.

Cuidado

Os provedores de imagem, vídeo e voz pagos cobram na sua conta de cada um. A licença AGPL-3.0 tem regras fortes se você usar o código dentro de um produto seu.

Prompt
Faça um vídeo vertical de 45 segundos, em português do Brasil, explicando [tema] para iniciantes. Use só imagens e vídeos de bancos gratuitos, música livre, narração com voz offline e legendas palavra por palavra. Antes de renderizar, me mostre o roteiro para eu aprovar.
Como instalar e usar1 etapa com comandos prontos para copiar

Antes de começar

  • Python 3.10 ou mais novo.
  • FFmpeg.
  • Node.js 18 ou mais novo.
  • Um agente de código (Claude Code, Cursor, Codex e outros).

Instalar

git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup

Para ver vídeos de demonstração sem nenhuma chave de API:

make demo
Custos

Segundo o README, o caminho com imagens de bancos gratuitos custa zero; com um provedor de imagem ou vídeo configurado, cerca de US$ 0,15 a 1,50 por vídeo; com tudo ligado, US$ 1 a 3.

Graft

trailhq/Graft
  • ★ 9,3 mil
  • Médio: precisa de agente de código

Monta um mapa (grafo) do seu código e entrega ao agente de programação, para ele parar de abrir arquivo por arquivo procurando onde está cada coisa. Funciona com Claude Code, Cursor, Codex e Gemini.

Números

No teste publicado pelo próprio projeto, comparado ao Claude Code sem o Graft: 46% menos chamadas de ferramenta, 42% menos tokens e 60% menos tempo.

Cuidado

Os números são do próprio projeto. Em projeto pequeno a diferença tende a ser pequena. O pacote de instalação se chama @nanonets/graft, mesmo o repositório estando em trailhq.

Prompt
Usando o mapa do Graft, me explique a arquitetura deste projeto em até 10 linhas e aponte os 3 arquivos mais importantes para eu entender primeiro.
Como instalar e usar1 etapa com comandos prontos para copiar

Instalar

Precisa do Node.js. Instale uma vez:

npm install -g @nanonets/graft

Na pasta do projeto (use --dry-run antes para ver o que ele vai alterar):

graft init --dry-run
graft init

codebase-memory-mcp

DeusData/codebase-memory-mcp
  • ★ 45,3 mil
  • Avançado: MCP

Um servidor MCP que indexa o repositório inteiro num grafo de funções, classes, chamadas e rotas. Responde perguntas de estrutura em menos de 1 milissegundo. É um executável só, sem runtime de linguagem e sem chave de API.

Cuidado

Só faz diferença para quem já usa agente de código com MCP em projeto grande. Para desinstalar: codebase-memory-mcp uninstall.

Prompt
Usando o codebase-memory, me diga: quem chama a função [nome]? O que pode quebrar se eu mudar a assinatura dela? Liste os arquivos afetados.
Como instalar e usar2 etapas com comandos prontos para copiar

Instalar (Mac ou Linux)

curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | bash

Instalar (Windows, PowerShell)

Invoke-WebRequest -Uri https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.ps1 -OutFile install.ps1
Unblock-File .\install.ps1
.\install.ps1
Depois de instalar
  • Reinicie o seu agente de código.
  • No Claude Code, confira com /mcp: deve aparecer codebase-memory-mcp.
  • Peça: "Index this project".
