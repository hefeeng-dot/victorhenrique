7 repositórios abertos que fazem o trabalho de serviços caros

Estes sete projetos fazem, de graça, o que muita agência e muito fornecedor cobram como serviço. O software é aberto e o código está no GitHub — o que não vem pronto é a instalação, a configuração no seu contexto e o acompanhamento. Essa parte é trabalho, e é ela que se cobra. Estrelas e licenças foram conferidas na API do GitHub em 06/10/2026: se algum número estiver diferente quando você olhar, o repositório é a fonte, não este texto.

01 · O CRM — trycompai/crm

O projeto
  • Repositório oficial: github.com
  • 11.037 estrelas · licença MIT (conferido em 06/10/2026)
O que ele substitui

07 · A leitura de papelada — PaddlePaddle/PaddleOCR

O projeto
  • Repositório oficial: github.com
  • 90.560 estrelas · licença Apache-2.0 (conferido em 06/10/2026)
O que ele substitui
  • Digitação de PDF, nota, cupom e ficha em papel
  • O trabalho que se cobra: padronizar a saída, conferir o que a leitura errou e integrar no sistema de destino
A regra que eu uso: a ferramenta é grátis; o que se cobra é o trabalho de colocar para funcionar. Comece por um só — o que mais dói no seu dia — e faça a implantação inteira antes de oferecer para outra pessoa. É essa implantação que vira o seu serviço.
